## Детали по каждому

### 1. chatterbox-multilingual — рекомендуемый

Источник: https://replicate.com/resemble-ai/chatterbox-multilingual

- 23 языка, русский есть (`language_id: "ru"`).
- Клонирование голоса по `reference_audio`: «even 3-10 seconds works». Для нашего ТЗ (20–30 с эталон) — с запасом.
- Входы: `text_to_synthesize`, `language_id`, `reference_audio`, `exaggeration` (0.25–2.0, нейтрально 0.5), `temperature` (0.05–5.0), `cfg_weight` (0.2–1.0, 0.5 для обычной речи), `seed`.
- **Ограничение: максимум 300 символов на запрос.** Сценарий 15–25 с — это 250–400 символов, то есть почти всегда 2 запроса. Нужна нарезка по предложениям + склейка через ffmpeg.
- Выход: 24 кГц.
- Встроенный нейроводяной знак (watermarking) — для медицинского контента скорее плюс: происхождение аудио проверяемо.
- Ограничения из README: короткий эталон (<2 с) не передаёт тембр; при кросс-языковом переносе ставить `cfg_weight: 0.0`; высокий `exaggeration` (>1.5) даёт артефакты.
- Цена: тарифицируется по секундам сгенерированного аудио, точную ставку подтвердить не удалось — смотреть на странице модели в кабинете Replicate.

Плюс для проекта: тот же `REPLICATE_API_TOKEN`, что и для липсинка, — один ключ на два шага.

### 2. ElevenLabs — если нужно максимальное качество

Источники: https://elevenlabs.io/docs/models, https://elevenlabs.io/docs/product-guides/voices/voice-cloning/instant-voice-cloning

- Русский поддерживается и в Multilingual v2 (29 языков), и в Eleven v3 (70+).
- Instant Voice Cloning: официальная рекомендация — **минимум 1 минута** чистой речи, оптимум 1–2 минуты, больше 3 минут вредит.
- Важно: ТЗ предполагает клон по 20–30 с. Для ElevenLabs этого мало — придётся записать ~1–2 минуты. Для chatterbox 20–30 с достаточно.
- Требования к записи: без реверберации и шума, ровный тон и темп, −23…−18 dB RMS, true peak −3 dB, MP3 ≥128 kbps.
- API: REST, ключ `xi-api-key`, эндпоинт `/v1/text-to-speech/{voice_id}`.
- Цена: ориентир из обзора — Starter $6/мес, Creator $22/мес; официальную сетку проверить перед покупкой.

### 3. VoiceKit (Т-Банк) — не подходит

Источники: https://www.tbank.ru/software/voicekit, https://developer.tinkoff.ru/voicekit/api/release-notes/releasenotestts

- Реальный продукт: облачный API распознавания и синтеза речи, русский язык нативный, голоса звучат естественно.
- Но: синтез доступен **только после заключения договора**, а клонирование голоса в публичной документации отсутствует — доступны фиксированные голоса.
- Критерий «клонировать голос врача» не выполняется → из списка кандидатов убираем.

### 4. FreedomSpeech — продукта не найдено

- Ни официального сайта, ни репозитория, ни упоминаний как SDK для Python с русским и клонированием.
- Вывод: название попало в ТЗ ошибочно (вероятно, артефакт предыдущего исследования). **Не закладывать в архитектуру.**

## Что это меняет в пайплайне

1. Шаг 2 (озвучка) реализуется на chatterbox-multilingual через Replicate — без второго вендора и второго счёта.
2. В `generate_audio()` появляется нарезка текста на куски ≤300 символов по границам предложений и склейка результатов.
3. Эталон голоса: 20–30 с чистой речи, mono, без музыки и эха → `assets/voice/reference.wav`.
4. ElevenLabs остаётся как аварийный вариант: если русская интонация chatterbox не устроит — переключаем провайдера, интерфейс функции не меняется.

## Какие ключи нужны

| Переменная | Обязателен | Для чего | Где взять |
|---|---|---|---|
| `REPLICATE_API_TOKEN` | да | озвучка (chatterbox) + липсинк (omni-human) | replicate.com → Account → API tokens |
| `ELEVENLABS_API_KEY` | нет | запасной TTS | elevenlabs.io → Profile → API keys |
| `LLM_API_KEY` + `LLM_BASE_URL` | да (шаг 1) | генерация сценария | у выбранного LLM-провайдера |

VoiceKit: понадобился бы договор с Т-Банком — не берём.
