## Статус задач
- `в работе` — агент активно работает над задачей
- `на проверке` — задача выполнена, ждёт ревью/мерж
- `завершено` — задача завершена и влита в main
- `заблокировано` — не может быть выполнена без внешней зависимости

## Правила работы
1. Каждый агент работает в своём Git Worktree, свою ветку.
2. Перед началом работы читать `COORDINATION.md` и `docs/agent-protocol.md`.
3. Брать задачу со статусом `ожидает` или `заблокировано` (если зависимости готовы), ставить `в работе`.
4. После завершения — коммит в свою ветку, пуш, обновить `COORDINATION.md` (статус → `на проверке`).
5. `agent-git` делает ревью, мержит в `main`, статус → `завершено`.
6. Никогда не коммитить напрямую в `main` (кроме `agent-git` после ревью).
7. `.env` с реальными ключами НЕ коммитится (в .gitignore).
