# Задача task-003: Git-репозиторий — защита main и организация мержей

## Описание
Агент `agent-git` отвечает за:
1. Настройку защиты ветки `main` на GitHub (запрет прямого пуша, обязательный PR/ревью).
2. Приём пушей от агентов `agent/local` и `agent/server` в их ветках.
3. Ревью изменений, мерж веток агентов в `main` после одобрения.
4. Обновление `COORDINATION.md` после каждого мержа (статус задач → `завершено`).
5. Поддержание чистоты истории коммитов.

## Границы (что можно трогать)
**Можно:**
- Ветки `agent/local`, `agent/server`, `agent/git` на GitHub.
- Ветка `main` (только через мерж из веток агентов).
- `COORDINATION.md` (обновление статусов после мержа).
- Настройки репозитория на GitHub (защита веток).

**Нельзя:**
- Модифицировать исходный код проекта напрямую в `main`.
- Коммитить в `main` без мерж-запроса от агента-владельца задачи.

## Критерии приёмки
- [ ] Ветка `main` защищена на GitHub (нет прямого пуша, требуется PR).
- [ ] Агент `agent-git` может принимать пуши от `agent/local` и `agent/server`.
- [ ] Пример одного успешного мержа ветки агента в `main` wykonan.
- [ ] `COORDINATION.md` актуализирован после мержа.
- [ ] Изменения закоммичены в ветку `agent/git` и запушены в origin.
- [ ] `COORDINATION.md` обновлён: статус task-003 → `завершено`.
