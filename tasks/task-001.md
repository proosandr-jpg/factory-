# Задача task-001: Структура координации агентов

## Описание
Создать инфраструктуру для координации трёх агентов (local, server, git) через Git:
- Файл `COORDINATION.md` — единая доска задач в корне репозитория.
- Каталог `tasks/` с файлами `task-*.md` — описания задач с границами и критериями приёмки.
- Файл `docs/agent-protocol.md` — инструкция по использованию протокола для двух других агентов.
- Git Worktree для каждого агента с отдельной веткой.

## Границы (что можно трогать)
**Можно:**
- `COORDINATION.md`
- `tasks/task-001.md`
- `docs/agent-protocol.md`
- Создание worktree в родительской директории репозитория (`../factory-agent-local/`, `../factory-agent-server/`, `../factory-agent-git/`)

**Нельзя:**
- Модифицировать исходный код проекта (`pipeline.py`, `heygen_client.py` и т.д.) — это задачи task-002 и task-003.
- Коммитить в `main` напрямую.

## Критерии приёмки
- [ ] `COORDINATION.md` создан в корне репозитория с таблицей агентов и задач.
- [ ] `docs/agent-protocol.md` создан с пошаговой инструкцией для агентов server и git.
- [ ] `tasks/task-001.md` создан с описанием этой задачи.
- [ ] Worktree `agent-local` создан для локального агента (ветка `agent/local`).
- [ ] Worktree `agent-server` создан для серверного агента (ветка `agent/server`).
- [ ] Worktree `agent-git` создан для гит-агента (ветка `agent/git`).
- [ ] Все изменения закоммичены в ветки агентов и запушены в origin.
- [ ] `COORDINATION.md` обновлён: статус task-001 → `завершено`.
